{# Convert marked runs to real blocks before printing. Painting a bar over live text is enough on screen, but not in a PDF: the characters are still in the document, so they can be selected, copied, or pulled out with a text extractor. The fix has to remove the characters, not cover them. Each run is measured first, then replaced with an empty block of the same width and height. Width is what keeps the line from re-wrapping; the small vertical adjustment puts the block back on the run's baseline, so nothing around it moves. The result prints as a bar and leaves no text behind. #} {% if redact %} {% endif %}
